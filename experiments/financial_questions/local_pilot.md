# Disclosed local workflow pilot

From the RAC research worktree:

```sh
python3 experiments/financial_questions/local_pilot.py --out <new-directory>
```

The parent must exist; an existing output directory is never overwritten.
This command makes no network calls. It freezes three synthetic cases, declares
two scripted systems and two scripted judge families, and composes blind request
projection/result binding, unchanged answer reports, ordered workflow receipts
and positive/negative scoring controls. It saves raw requests, private bindings,
responses, answers, receipts, predeclared score intervals and reports.

The workflow compares synthetic A/B values, introduces a contradictory observation
and adds a synthetic budget/loss constraint. The supported script revises its
view and waits for missing sizing evidence. The bad script fabricates an
observation, retains a stale premise and gives irrelevant next steps. Scores
are hardcoded fixture labels, not inferred by a model or calibrated by humans.
All user state, observations, clocks, metrics, answers and judge families are
synthetic. No visible chart, actual-market demonstration, paid model, account,
order or live Edge request occurs. Protocol readiness never means V1 readiness.

The one composed regression reaches six answers and twelve bound judgments,
six retained workflow steps and a passing paired control audit. Replacing all
judgments with fours fails the saved negative audit. Independent catalog
admission remains a separate gate; this pilot does not pretend its A/B symbols
are a 17-market catalog. Real listing provenance, authenticated read-only Edge
authority, broader workflows, actual judges, calibration and independent
administration remain open. Existing wire versions are unchanged. Rollback
discards this additive pilot consumer while preserving its evidence and history.
