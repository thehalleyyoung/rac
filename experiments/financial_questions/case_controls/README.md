# Synthetic manifest controls

These two questions, requested specs and classifier labels are scripted test
inputs. They are not live model outputs, market observations, verified listings,
financial answers or human-calibrated labels. The options contract remains
unresolved. No answer execution or financial scoring is performed.

The policy automatically fills general run requirements and assigns one premise
verification challenge and one ordinary hypothetical question. The control
tests artifact compilation, conditional quotas, classifier-axis agreement and
read-only constraints. Passing it does not establish a valid financial rubric
or representative question distribution.

Use `benchmark_cases.py freeze --generated-run control=<this-directory>
--policy <this-directory>/policy.json --out <new-directory>`, then verify the
bundle. Omit the options row or alter its instrument to create a failing
control; never change the passing fixture in place.
